Authoritative, 100% offline trophy guide, progress tracker, and platinum roadmap for **Grand Theft Auto VI** on PlayStation 5.

## Features
- **Official 55 Trophies:** Full database matching PlayStation 5 Network Manifest (1 Platinum, 2 Gold, 6 Silver, 46 Bronze).
- **Comprehensive Cited Guidance:** Every trophy features practical, actionable step-by-step guidance in our own words with verified source citations (Exophase, Leonida Crime Gazette, PSNProfiles telemetry).
- **Platinum Roadmap:** 4-stage sequential breakdown with difficulty rating (4.5/10), estimated completion time (75-85 hours), and playthrough structure.
- **Missables Early Warning:** Dedicated tracking and lockout prevention for high-risk trophies (*Sneakthief*, *Actions Speak Louder*, *Retail Therapy*).
- **Interactive Tracker:** Browser-local progress persistence (`localStorage`), category & grade filters, instant search, export/import JSON, and spoiler masking.
- **Zero Network Requests:** Pure vanilla ES modules and responsive synthwave UI designed to run completely offline.

## Quick Start
Serve the offline web app locally:
```bash
node serve.ts --port 8080
```
Open [http://localhost:8080](http://localhost:8080) in any modern browser.

## Build Dossier
```bash
MAKEFUN_OUTPUT_DIR=out node main.ts
```
